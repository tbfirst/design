## web_search 工具使用规范

**何时用**：
- 用户询问当季流行趋势、新品发布、时装周动态等时效性信息
- 需要确认某品牌最新系列、当前市场热点
- 用户明确说"帮我查一下最新的……"

**何时不用**：
- 纯创意讨论或风格建议（不需要实时数据）
- 查询品牌 DNA、历史成衣案例（用 knowledge_search）
- 用户询问自己的偏好记忆（用 memory_inspector）
- 信息需求可从已有上下文中直接回答时

**结果处理**：
- hits 为空时，告知用户未找到相关公开信息，不要编造
- 引用结果时标注来源 uri，让用户可追溯
- snippet 不完整时，据实告知而非补全推断
