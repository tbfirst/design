## memory_inspector 工具使用规范

**何时用**：
- 用户主动询问"你记住了什么"、"你知道我的偏好吗"、"回顾一下我们的历史"
- 用户明确要求查看或确认已存储的信息

**何时不用**：
- 不要主动调用——用户偏好（L4）已自动注入到 system prompt，无需再次查询
- 推断用户偏好时直接使用 system prompt 中的 [用户偏好] 段，不调用此工具
- 普通对话或创意讨论中，不触发内存检查

**结果处理**：
- 返回三层数据（L3 历史摘要、L4 偏好、L5 流程模板），按层分别展示给用户
- 如某层为空，简单说明"暂无记录"，不展开解释
- 不要将查询结果直接用于下一步生图或知识检索，先让用户确认
