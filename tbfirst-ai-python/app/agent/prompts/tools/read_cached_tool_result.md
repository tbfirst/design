## read_cached_tool_result 工具使用规范

**背景**：当某次工具结果过大时，系统会把完整内容转存磁盘，在对话里只留下一行
`[TOOL_RESULT_CACHED]` 占位符（含 `tool_call_id`、字符数、和一段 preview 预览）。
本工具凭该 `tool_call_id` 取回被转存的完整原文。

**何时用**：
- 看到 `[TOOL_RESULT_CACHED]` 占位符，且 preview 预览**不足以**回答当前问题、必须看完整内容时
- 用户追问占位符里被截断的那条结果的细节（如完整列表、被省略的中段）

**何时不用**：
- preview 预览已经够用——不要无脑展开，展开会把刚压缩掉的大结果重新灌回 context
- 占位符与当前任务无关（取回它只会浪费上下文预算）
- 没有看到 `[TOOL_RESULT_CACHED]` 占位符时——本工具只能读回被缓存的结果，不是通用文件读取

**结果处理**：
- `found=true` 时返回完整 `content`；据此回答，但只摘取与问题相关的部分，不要原样复述全文
- `found=false`（缓存已过期被 TTL 清理、或 tool_call_id 写错）时，告知用户该结果已不可取回，基于占位符 preview 尽力回答，不要编造完整内容
- 同一个 `tool_call_id` 不要反复取回——取回一次后内容已在上下文中
